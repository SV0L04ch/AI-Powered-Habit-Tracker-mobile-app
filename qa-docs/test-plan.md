# Тест-план проекта: мобильное приложение «Трекер привычек с ИИ-поддержкой»

## Scope тестирования

**In‑scope (что тестируем)**
- Управление привычками: создание, редактирование, удаление (положительные / отрицательные)
- Триггеры и логика: напоминания по конкретному времени, учёт привычек по количеству раз в день
- Интеграция с ИИ (LLM): генерация предложений о частичном выполнении, мотивирующие советы при срыве, естественно-языковые отчёты (связь привычек и погоды)
- Аналитика и внешние данные: интеграция с OpenWeather API, корреляция погоды с действиями пользователя, генерация анонимной городской сводки
- Инфраструктура: push-уведомления (напоминания и вечерняя сводка)

**Out‑of‑scope (что не тестируем)**
- Точность метеоданных от стороннего API (только факт получения и обработки)
- Психологическая ценность советов ИИ (только формат, отсутствие ошибок)
- Безопасность облачных API нейросетей на стороне провайдера

## Виды тестирования
- Функциональное (ручное + автоматизированное)
- Интеграционное (клиент – бэкенд – API погоды – API ИИ)
- Кроссплатформенное (Android через эмуляцию в Playwright)
- UI/UX (удобство отметки выполнения, отображение прогресса)
- Нагрузочное (k6, 1000+ VU)
- Регрессионное (после каждого релиза)
- Безопасности (JWT, SQL-инъекции, доступ к чужим данным)

## Приоритеты (Priority)
- **P0 (критичные)**: регистрация, авторизация, создание привычек, отметка выполнения/срыва, сохранение данных.
- **P1 (высокие)**: push-уведомления, погода, базовые советы ИИ, отображение прогресса.
- **P2 (средние)**: персональная сводка, частичное выполнение, городская сводка.
- **P3 (низкие)**: визуальные эффекты, фильтры в статистике.

## Классификация Severity
- **S1 (Blocker)**: приложение падает, невозможно пройти регистрацию/авторизацию, данные не сохраняются.
- **S2 (Critical)**: нарушена ключевая бизнес-логика (ИИ не даёт советы, уведомления не работают).
- **S3 (Major)**: ошибка в неключевой функции, есть обходной путь (некорректная сводка по городу, невозможность редактирования).
- **S4 (Minor)**: опечатки, недочёты интерфейса.
- **S5 (Trivial)**: незначительное отклонение от дизайна, медленная анимация.

## Ключевые user stories для проверки
1. Дождливая погода → ИИ в сводке отмечает связь с привычкой (например, «пьёте меньше воды»).
2. Городская сводка: отображаются агрегированные данные без привязки к конкретному пользователю.
3. Частичное выполнение привычки → ИИ предлагает альтернативный вариант.
4. Срыв вредной привычки → ИИ даёт мотивирующий совет.
