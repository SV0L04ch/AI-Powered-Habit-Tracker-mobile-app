# Smoke-тестирование (быстрая проверка после сборки)

| № | Проверка | Ожидаемый результат |
|---|----------|----------------------|
| 1 | Регистрация нового пользователя | Редирект на /habits, пользователь создан |
| 2 | Логин существующего пользователя | Редирект на /habits |
| 3 | Создание положительной привычки | Привычка отображается в списке |
| 4 | Создание отрицательной привычки | Привычка с маркером «вредная» |
| 5 | Отметка выполнения привычки | Статус меняется на «Выполнено» |
| 6 | Удаление привычки | Привычка исчезает из списка |
| 7 | Выход из системы (logout) | Редирект на /login, доступ к /habits закрыт |
| 8 | Попытка доступа к /habits без логина | Редирект на /login (или 401) |
| 9 | Получение погоды для существующего города | HTTP 200, температура не null |
| 10 | Получение погоды для несуществующего города | HTTP 404 или 400 (не 200 с заглушкой) |
