# Smoke-тестирование (быстрая проверка после сборки)

| № | Проверка | Ожидаемый результат | Статус |
|---|----------|----------------------|--------|
| 1 | Регистрация нового пользователя | Редирект на /habits, пользователь создан | Passed |
| 2 | Логин существующего пользователя | Редирект на /habits | Passed |
| 3 | Создание положительной привычки | Привычка отображается в списке | Passed |
| 4 | Создание отрицательной привычки | Привычка с маркером «вредная» | Passed |
| 5 | Отметка выполнения привычки | Статус «Выполнено» | Passed |
| 6 | Удаление привычки | Привычка исчезает из списка | Passed |
| 7 | Выход из системы (logout) | Редирект на /login | Passed |
| 8 | Попытка доступа к /habits без логина | Редирект на /login (или 401) | Passed |
| 9 | Получение погоды для существующего города | HTTP 200, температура не null | Passed |
| 10 | Получение погоды для несуществующего города | HTTP 404 | Passed |
