# Plan: Endpoint Fixes, Optimization & Design Improvements

## [S1] Problem Summary

The project has three categories of issues:

1. **Broken endpoints** — 13 of 19 backend controllers are missing `[Authorize]`, causing 500 errors instead of proper 401s
2. **Design regression** — Active routes point to older, minimal page implementations while premium-quality pages exist unused
3. **Architecture debt** — Duplicate animations, hardcoded colors, inconsistent component usage, orphaned API integrations

## [S2] Design References

Popular habit tracker apps to draw inspiration from:

| App | Key Design Pattern | What to Adopt |
|-----|-------------------|---------------|
| **Streaks** (Apple) | Circular progress rings, clean minimal layout, color-coded habits | Progress visualization on HabitsPage |
| **Habitify** | Modern card-based layout, smooth transitions, analytics dashboard | DashboardPage metrics, insights |
| **Done** | Color-coded categories, simple toggle interactions, clean typography | Habit completion UX |
| **Loop Habit Tracker** | Heatmap calendar, material design, data visualization | Stats/Insights pages |
| **Productive** | Premium animations, glass morphism, smooth page transitions | Landing page, overall feel |

**Design direction:** The project already has a solid Claude.ai-inspired warm palette (#faf8f5, #d97706, #059669). Keep this identity but adopt the premium polish from the unused newer pages.
