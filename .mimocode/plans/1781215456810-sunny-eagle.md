# Implementation Plan: Fix multi-count habit bug + redesign all pages

## Task 1: Fix multi-count habit completion (useHabitsStore.js)

**File**: `frontend/src/store/useHabitsStore.js`

**Problem**: `markHabitCompleted` sends `status: COMPLETED` for ALL positive habits, ignoring `triggerType === 2` (CountPerDay). Multi-count habits should increment `partialValue` by 1 each click.

**Fix**: Replace the `markHabitCompleted` function (lines 126-162) with:

```js
markHabitCompleted: async (habit) => {
    const currentEntry = get().entriesByHabitId[habit.id];
    const isCompleted = currentEntry?.status === COMPLETED;
    const today = todayIso();
    set({ actionLoadingId: habit.id, error: null });

    try {
      let payload;

      if (!habit.isPositive) {
        payload = { date: today, relapseCount: 1, note: null };
      } else if (Number(habit.triggerType) === 2) {
        const target = Number(habit.triggerValue) || 1;
        const current = currentEntry?.partialValue || 0;

        if (isCompleted) {
          payload = { date: today, status: 3, partialValue: null, note: null };
        } else {
          const next = current + 1;
          if (next >= target) {
            payload = { date: today, status: COMPLETED, partialValue: next, note: null };
          } else {
            payload = { date: today, status: 2, partialValue: next, note: null };
          }
        }
      } else {
        payload = {
          date: today,
          status: isCompleted ? 3 : COMPLETED,
          partialValue: null,
          note: null,
        };
      }

      const entry = currentEntry
        ? await updateHabitEntry(habit.id, currentEntry.id, payload)
        : await createHabitEntry(habit.id, payload);

      set((state) => ({
        entriesByHabitId: {
          ...state.entriesByHabitId,
          [habit.id]: entry,
        },
        actionLoadingId: null,
      }));
      return entry;
    } catch (err) {
      set({ error: getErrorMessage(err), actionLoadingId: null });
      return null;
    }
  },
```

**Behavior after fix**:
- Multi-count habit (triggerType=2, triggerValue=5): Click 1 → partialValue=1 (20%), Click 2 → 2 (40%), ... Click 5 → 5 (100%, status=COMPLETED)
- Click again when completed → unmarks (status=3/Skipped)
- Simple habits (triggerType=1): Unchanged toggle behavior
