# Full Frontend Redesign — FINAL PLAN

## Design Concept: "Flowstate"

Премиальный хабит-трекер. Минимализм, glass-morphism, fluid-анимации. Всё свежее — 2025-2026 дизайн-тренды.

**References used:**
- **Linear Login** — split-screen auth с animated blob background
- **Stripe** — gradient mesh, parallax landing, layered sections
- **Framer** — scroll-triggered animations, interactive demos
- **Raycast** — compact sidebar, command palette, keyboard-first
- **Cal.com** — numbered steps, clean cards, testimonials, FAQ
- **Resend** —极致 minimalism, gradient accents, dark hero

- Sticky top-bar: **Logo** | Features▾ | Pricing | About | Sign In | **Get Started** (gradient btn)

- **Command Palette** (Ctrl+K): быстрый поиск по страницам (Raycast стиль)

## 2. Auth Pages (Linear Login)

### Login (`/login`) — Split Screen
- **Левая часть** (55%): Animated gradient blob background (3 цвета: primary, accent, accent-2), плавно двигаются через CSS keyframes. Поверх — tagline: "Build better habits." + animated stats counter
- **Правая часть** (45%): Чистая форма с floating-label inputs, gradient "Sign In" button, "Forgot password?" + "Create account" links
- **Анимации**:
  - Blob background: 3 radial-gradient circles, бесконечный float (CSS `@keyframes`)
  - Form fields: staggered appear (каждое поле появляется с 100ms задержкой)
  - Button hover: glow + slight scale
  - При успешном логине: form → dot → expand в dashboard (Framer Motion `layoutId`)

### Register (`/register`) — Multi-step (Cal.com numbering)
- **3 шага с progress bar**:
  1. **Account**: Email + город (с dropdown/search)
  2. **Security**: Password + confirm (с animated strength ring)
  3. **Interests**: Выбор 3+ привычек из каталога (анимированные toggle cards)
- **Между шагами**: Lottie animation (1.5s) — построение дерева / рост растения / забег
- **Финал**: Canvas confetti → "Welcome!" → redirect
- **Анимации**:
  - Step transitions: slide left/right (Framer Motion `AnimatePresence mode="wait"`)
  - Strength ring: SVG circle с animated stroke-dashoffset
  - Toggle cards: scale bounce при выборе

## 5. Animations

### Page Transitions (Framer Motion)
- Route change: `AnimatePresence mode="wait"` + fade + slide-up 20px
- Shared elements: `layoutId` для card → detail transitions

### Micro-interactions
- **Button click**: Ripple circle from cursor position (CSS `@keyframes ripple`)
- **Checkbox**: SVG checkmark draw + completion pulse + confetti (at milestones)
- **Card hover**: `translateY(-2px)` + shadow grow (CSS transition)
- **Tab switch**: Animated underline slides to active (CSS `transform: translateX`)
- **Progress bar**: Animated fill from left + gradient shimmer
- **Streak fire**: Flickering flame icon animation
- **Level up**: Full-screen flash + level badge zoom-in (Framer Motion)

### Auth Animations
- **Blob background**: 3 radial-gradient circles, `@keyframes float` (infinite, 15-20s)
- **Form stagger**: Each field appears with 100ms delay (Framer Motion stagger)
- **Password strength**: SVG ring с animated stroke-dashoffset
- **Login success**: Form → point → expand (Framer Motion `layoutId`)

### Loading States
- **Skeleton**: Shimmer placeholder (CSS `@keyframes shimmer`)
- **Page loader**: Logo pulse (existing splash, improved)
- **Data fetch**: Inline spinner on buttons
