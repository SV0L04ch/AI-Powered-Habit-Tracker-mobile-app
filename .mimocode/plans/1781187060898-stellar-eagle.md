- **Clean typography hierarchy** — clear distinction between headings, body, captions
- **Bottom-sheet patterns** — mobile-first modals slide up from bottom

## Part 2: Email Authorization Overhaul

### 2.1 Current Problem

All emails go to Mailhog regardless of whether it's a real or test account. No Gmail validation exists.

### 2.2 New Logic

**Email routing by domain:**

| Email Domain | Behavior |
|---|---|
| `*@gmail.com` | Send real email via Gmail SMTP (production) |
| `*@mailhog.test` or any non-gmail | Send to Mailhog (development/testing) |

**Implementation:**

#### Backend Changes

**`EmailService.cs`** — add email routing logic:

```csharp
public async Task SendConfirmationEmailAsync(string email, string token)
{
    if (IsTestEmail(email))
    {
        await SendViaMailHog(email, token);
    }
    else if (IsGmailAddress(email))
    {
        await SendViaGmailSmtp(email, token);
    }
    else
    {
        throw new ArgumentException("Only Gmail addresses are supported for production email.");
    }
}

private bool IsTestEmail(string email)
{
    // Test emails: any non-gmail address goes to Mailhog
    return !email.EndsWith("@gmail.com", StringComparison.OrdinalIgnoreCase);
}

private bool IsGmailAddress(string email)
{
    return email.EndsWith("@gmail.com", StringComparison.OrdinalIgnoreCase);
}
```

**`AuthService.cs`** — add Gmail validation on registration:

```csharp
public async Task<IdentityResult> RegisterAsync(RegisterRequestDto request)
{
    // Validate Gmail for production emails
    if (!IsTestEmail(request.Email) && !IsGmailAddress(request.Email))
    {
        return IdentityResult.Failed(new IdentityError
        {
            Code = "InvalidEmail",
            Description = "Only Gmail addresses are supported. Use a test email for development."
        });
    }
    // ... existing registration logic
}
```

**FluentValidation** — add Gmail validation to `RegisterRequestDtoValidator`:

```csharp
RuleFor(x => x.Email)
    .NotEmpty().WithMessage("Email is required")
    .EmailAddress().WithMessage("Invalid email format")
    .Must(email => email.EndsWith("@gmail.com") || IsTestEmail(email))
    .WithMessage("Only Gmail addresses are supported for production");
```

**SMTP Configuration** — add Gmail SMTP settings to `appsettings.json`:

```json
{
  "EmailSettings": {
    "GmailSmtpServer": "smtp.gmail.com",
    "GmailSmtpPort": 587,
    "GmailSenderEmail": "your-app@gmail.com",
    "GmailSenderPassword": "app-specific-password",
    "GmailEnableSsl": true
  }
}
```

**Environment Variables** — add to `.env.example`:

```bash
# Gmail SMTP (for production email)
GMAIL_SENDER_EMAIL=your-app@gmail.com
GMAIL_APP_PASSWORD=your-app-specific-password
```

**RegisterPage.jsx** — add Gmail hint:


**Technical foundation**: CSS `@keyframes` + `animation` + `transition` + `transform` (no heavy JS animation libraries — pure CSS for 60fps performance).

```jsx
class ErrorBoundary extends React.Component {
  state = { hasError: false };

  static getDerivedStateFromError(error) {
    return { hasError: true };
  }

  componentDidCatch(error, errorInfo) {
    console.error('Error caught:', error, errorInfo);
    // Send to error reporting service
  }

  render() {
    if (this.state.hasError) {
      return <ErrorFallback onRetry={() => this.setState({ hasError: false })} />;
    }
    return this.props.children;
  }
}
```
